# Das Ordinarium der Messe für den Satz mit Text (Phase 12).
#
# Quelle: Graduale Romanum, Solesmes 1961, Kyriale: Messe VIII (Kyrie, Gloria, Sanctus,
# Benedictus, Agnus Dei) und Credo I. Text, Schreibung (ae, J), Akzente, Silbentrennung und
# Zeichensetzung wie dort, Wort für Wort an den Scans geprüft. Nur Wörter ab drei Silben tragen
# einen Akut (Dó-mi-ne, aber De-us). Die Intonationen (Gloria in excelsis Deo, Credo in unum
# Deum) fehlen, weil die Polyphonie mit Et in terra und Patrem beginnt.
#
# Jeder Abschnitt beginnt mit einer Kopfzeile [id] kind=short|long de="…" en="…". Danach folgt
# der Text, ein Sinnabschnitt je Zeile: Zeile n eines Abschnitts ist der Sinnabschnitt n in
# ID:A-B. Ein Sinnabschnitt endet mit , ; : (Zwischenschluss) oder . ? ! (Satzende).
#
# Zwei Marken ergänzen den Text der Bücher (Zarlinos „alcuna sua parte“):
#   /  vor einem Wort: Hier beginnt ein Schlussteil, der für sich wiederholt werden kann
#      (Ký-ri-e / e-lé-i-son); davor darf eine Pause stehen.
#   |  zwischen zwei Wörtern: eine Zäsur, an der eine Pause stehen darf.
